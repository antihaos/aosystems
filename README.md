# AOSystems

Корпоративный сайт компании **AOSystems** — разработка программного обеспечения в области
искусственного интеллекта и информационных систем.

Тёмная тема с неоновой подсветкой, современный и адаптивный дизайн.
Стили на **Tailwind CSS** (Play CDN, без сборки) + компактный кастомный CSS для
декоративных эффектов. Статический сайт — быстрая загрузка, лёгкий деплой.

## Возможности

- **Tailwind CSS** (Play CDN) с кастомной неоновой темой (cyan / violet).
- **Тёмная тема** с неоновыми акцентами, декоративным фоном (сетка + градиентные пятна).
- **Адаптивность** — корректное отображение на мобильных, планшетах и десктопе.
- **Секции:** Hero, Услуги (4 карточки), О компании (с цифрами), Контакты (форма).
- **Интерактив:** бургер-меню, плавное появление секций при скролле,
   активный пункт меню, валидация формы, автоподстановка года.
- **Доступность:** семантическая разметка, `aria`-атрибуты, поддержка
   `prefers-reduced-motion`.

## Локальный запуск

Откройте `index.html` в браузере:

```bash
open index.html
```

Или запустите локальный статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

> Tailwind подключается через Play CDN (`https://cdn.tailwindcss.com`),
> поэтому для отображения стилей нужен доступ в интернет.

## Деплой

Проект готов к размещению на **GitHub Pages** (файл `CNAME` указывает домен
`aosystems.ru`). Достаточно загрузить содержимое репозитория.

## Технологии

- HTML5
- **Tailwind CSS** (Play CDN) + кастомный CSS (Grid, Flexbox, `backdrop-filter`, `text-shadow`)
- Vanilla JavaScript (ES6, `IntersectionObserver`)
- Без сборщиков и зависимостей
