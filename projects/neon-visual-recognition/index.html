Настройки распознавания
Запустите локальный сервер: vllm serve <модель> — OpenAI-совместимый API будет доступен по указанному адресу. Данные не покидают ваш компьютер.
Полностью офлайн-распознавание: модель выполняется на вашем GPU прямо в браузере (технология WebLLM / WebGPU). При первом запуске веса модели скачиваются и кэшируются, дальше работает без интернета. Требуется браузер с WebGPU (Chrome / Edge).
Классический OCR работает офлайн прямо в браузере. Для формул и таблиц рекомендуется LLM (API, vLLM или офлайн VLM) — LaTeX и Markdown доступны только через них.
Авторазметка документа
Алгоритм обрабатывает каждую страницу документа: находит связанные области содержимого и классифицирует их — текст, таблицы (по сетке линий), диаграммы, изображения и формулы.

Справка · NEON VISUAL RECOGNITION

      

        
        
      

    

    

      
Загрузка изображений и многостраничных PDF, разметка на области (текст, изображения, таблицы, диаграммы, формулы), автоматическая разметка всех страниц, распознавание через мультимодальные LLM: внешний или локальный сервер vLLM (gemma4 / qwen3.8), офлайн-модель прямо в браузере (WebLLM) или OCR Tesseract. Экспорт результата в DOCX постранично. Проекты хранятся в IndexedDB.
