Подключение · RFC 7118

Транспорт WebSocket с subprotocol «sip», Via SIP/2.0/WSS, Contact ;transport=ws

Пароль хранится только в памяти вкладки и не записывается в localStorage. Для страницы по HTTPS требуется wss://. Пример Asterisk: wss://host:8089/ws (chan_pjsip, transport-wss).
