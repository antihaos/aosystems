Правила линий

DND отклоняет вызовы кодом 603. Переадресация отвечает 302 Moved Temporarily с новым Contact — вызывающий перезванивает автоматически.

Один ПК запускает хаб, остальные открывают приложение в браузере. Сигнализация через хаб, голос — напрямую между ПК по WebRTC.

Сервер для локальной сети

Браузер не умеет слушать порт, поэтому на одном ПК запускается лёгкий Node.js-сервер без зависимостей: он отдаёт это приложение по HTTP и ретранслирует SIP.

node monosip-lan.js
Файл самодостаточный: приложение вшито внутрь. Node.js ≥ 16, пакеты не нужны. Сервер напечатает адреса http://192.168.x.x:8080.

Как запустить

На ПК-сервере скачайте monosip-lan.js и выполните node monosip-lan.js, разрешите порт в брандмауэре.
На всех ПК одной подсети откройте http://IP-сервера:8080.
На сервере роль «Сервер (хаб)» → Подключить: АТС включится автоматически.
На клиентах роль «Клиент» → Подключить и задать уникальные номера.
Звоните, объединяйте в конференцию и переводите — всё работает между разными ПК.
