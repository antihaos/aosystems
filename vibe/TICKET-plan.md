# TICKET-plan: Корпоративный сайт AOSystems

## Task

Создать с нуля корпоративный одностраничный сайт для организации AOSystems, занимающейся разработкой софта в области ИИ и информационных систем. Сайт — статический, без сборки (чистый HTML/CSS/JS), в тёмных тонах с неоновой подсветкой (акценты cyan/violet), стильный и современный. Контент — на русском языке. Секции: Hero, Услуги, О компании, Контакты (форма). Проект размещается на GitHub Pages (домен aosystems.ru, файл `CNAME` уже существует).

## Plan Structure

- Создание базовой структуры проекта (index.html, favicon, папки css/js).
- Реализация стилей: тёмная тема, неоновые акценты, адаптивность, анимации.
- Реализация интерактивности: меню, скролл-анимации, обработка формы, текущий год.
- Обновление документации и верификация.

## Execution Plan

### Stage 1: Создание каркаса HTML и favicon
**What to add/implement:**
- Создать `index.html` — семантическая разметка одностраничника: `<header>` (навигация с логотипом AOSystems, ссылки на секции #services, #about, #contacts), `<main>` (секции `#hero`, `#services`, `#about`, `#contacts`), `<footer>` (копирайт с span `#year`).
- Секция `#hero`: заголовок «Разрабатываем ИИ и информационные системы», подзаголовок, две CTA-кнопки («Наши услуги», «Связаться»).
- Секция `#services`: сетка из 4 карточек услуг (Разработка ИИ-решений, Информационные системы, Интеграции, Сопровождение и поддержка) с неоновыми иконками (inline SVG).
- Секция `#about`: описание компании, ключевые цифры/факты (список).
- Секция `#contacts`: контактные данные (email, телефон, адрес) и форма обратной связи (поля: имя, email, сообщение) с кнопкой отправки.
- Подключить `css/styles.css` и `js/main.js` (атрибут `defer`), favicon `favicon.svg`.
- Создать `favicon.svg` — минималистичная неоновая буква «A» на тёмном фоне (128x128).
- Проверить валидность разметки: закрыты все теги, уникальные id секций.

**Files to edit/create:**
- `index.html` — создать, полная разметка всех секций.
- `favicon.svg` — создать, SVG-иконка.

**Verification commands:**
- `grep -c 'id="hero"' index.html && grep -c 'id="contacts"' index.html` — обе секции присутствуют.
- Открыть `index.html` в браузере — каркас отображается без ошибок консоли.

### Stage 2: Реализация стилей — тёмная тема и неоновые акценты
**What to add/implement:**
- Создать `css/styles.css`:
  - CSS-переменные в `:root`: `--bg` (#0a0e17), `--bg-alt` (#0f1524), `--surface` (#131a2b), `--text` (#e6ecf7), `--muted` (#8b96ad), `--neon-cyan` (#00e5ff), `--neon-violet` (#8a2be2), `--border` (rgba(0,229,255,0.2)), `--radius`, `--transition`.
  - Глобальный сброс (`box-sizing: border-box`, `margin: 0`), `font-family` (системный стек), `scroll-behavior: smooth`.
  - Декоративный неоновый фон: градиентные радиальные пятна (cyan/violet) + эффект сетки/скан-линий через `background` на `body` или псевдоэлемент, с `background-attachment: fixed`.
  - Стили для `header` (sticky, blur-подложка `backdrop-filter: blur(12px)`, border-bottom неоновый), логотип с `text-shadow` неона, бургер-меню (скрытое на десктопе).
  - Стили секций: отступы `padding: 96px 0`, заголовки с неоновым `text-shadow`, разделители градиентной линией.
  - Карточки услуг: `border: 1px solid var(--border)`, `background: var(--surface)`, `border-radius`, glow при `:hover` (`box-shadow: 0 0 24px rgba(0,229,255,0.25)`, transform translateY).
  - Стили формы: тёмные поля ввода с неоновой рамкой при `:focus`, кнопка-градиент cyan→violet с glow.
  - Медиа-запросы: адаптивность для планшетов (≤768px) и мобильных (≤480px): сетка услуг в 1 колонку, бургер-меню активно, уменьшенные отступы.

**Files to edit/create:**
- `css/styles.css` — создать, полные стили всех компонентов.

**Verification commands:**
- Открыть `index.html` в браузере (или `open index.html`) — тёмная тема и неоновая подсветка отображаются.
- Проверить адаптивность через DevTools (ширина 375px и 1440px).

### Stage 3: Интерактивность — JS
**What to add/implement:**
- Создать `js/main.js`:
  - Бургер-меню: переключение класса `open` на навигации, закрытие по клику на ссылку.
  - Плавное появление секций при скролле: `IntersectionObserver` добавляет класс `visible` элементам с классом `reveal` (заголовки, карточки).
  - Автоподстановка текущего года в `#year` через `new Date().getFullYear()`.
  - Обработчик отправки формы `#contact-form`: `preventDefault()`, базовая валидация (заполнены имя и email), вывод сообщения об успехе в элементе `#form-status`, сброс формы.
  - Установка активного пункта меню при скролле через `IntersectionObserver` (класс `active`).

**Files to edit/create:**
- `js/main.js` — создать, все обработчики.
- `index.html` — добавить класс `reveal` к заголовкам и карточкам секций, id `#contact-form` и `#form-status`, класс `nav-toggle` для бургера.

**Verification commands:**
- `node --check js/main.js` — синтаксис корректен.
- Открыть `index.html` — меню работает, анимации появляются при скролле, форма показывает сообщение об успехе, год актуален.
